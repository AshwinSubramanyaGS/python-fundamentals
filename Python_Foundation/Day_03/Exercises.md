## Level 4 – Integrated scenario

H06 – Enterprise application

Employee Training and Certification Management Platform

An organization manages employees, training programmes, certification policies and employee performance.

Develop an application supporting:

- Employee creation and validation.
- Multiple employee categories.
- Reusable business functions.
- Employee registration and lookup.
- Standard and advanced certification rules.
- Role-based report access.
- Execution logging through decorators.
- Performance and department-wise reporting.
- Exception handling.
- Type annotations and automated tests.

Technical constraints:

- Use classes, inheritance, encapsulation and polymorphism.
- Use functions with suitable parameter and return types.
- Use at least two decorators.
- Use an abstract base class or another well-defined common interface.
- Use composition where appropriate.
- Do not place all application logic in one class.
- Run Ruff, mypy and Bandit.
- Write at least five meaningful automated tests.

Expected deliverable: A small modular Python application rather than a single procedural script.
